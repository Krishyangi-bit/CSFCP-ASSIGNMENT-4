# CSFCP-ASSIGNMENT-4

CHOSEN PROJECT: CALCULATOR 

#Project Title & Description:--
Calculator is a Python-based command-line calculator that allows users to enter multiple numbers and perform operations like addition, subtraction, multiplication, and division. Unlike basic calculators that only take two inputs, this version runs in a loop and accepts unlimited numbers until the user types “done”. It’s designed for beginners to understand loops, lists, and input handling.

#Installation & Usage Instructions:--

Requirements:
Python 3 or above

Steps to Run:
1)Install VS Code on your system.
2)Download or copy the calculator.py file into a folder.
3)Open a terminal or command prompt in that folder.
4)Run the program
5)Enter numbers one by one.
6)Type done to finish input.
7)Select an operation (+ - * /).
8)Continue calculating until you choose to exit.
